# 🚗 Auto Kurd — Car Painting & Detailing Portfolio

A modern, responsive Persian (RTL) portfolio website for **Auto Kurd**, focused on professional car painting, polishing, detailing, PPF, and vehicle care services.

## ✨ Features

- 🎨 Professional car painting and color services
- ✨ Paint recovery, waxing, and polishing
- 🧼 Full vehicle washing and detailing
- 🛡️ PPF and car protection services
- 🚘 Services for passenger cars
- 🚛 Services for heavy vehicles and trucks
- 🏍️ Motorcycle services
- 📱 Fully responsive layout for desktop, tablet, and mobile
- 🍔 Responsive hamburger navigation on smaller screens
- 🌙 Dark visual design with red accent colors
- 🇮🇷 Persian RTL interface
- 📞 Contact section with phone, location, working hours, and social links

## 🛠️ Built With

- **HTML5**
- **CSS3**
- **JavaScript**
- **Remix Icon**
- Responsive Design
- CSS Custom Properties (Variables)

## 🎯 Main Sections

### 🏠 Hero
Introduces the Auto Kurd brand and professional car painting service.

### 🔧 Services
Displays the available automotive painting, polishing, detailing, protection, and vehicle-care services.

### 👨‍🎨 About
Introduces the professional background, experience, materials, attention to detail, and commitment to customers.

### 📞 Contact
Provides contact information, working hours, location, and social media links.

## 📱 Responsive Design

The website includes responsive breakpoints for:

- Desktop
- Tablet
- Mobile
- Small mobile screens

The navigation changes to a hamburger menu on smaller screens and the service cards adapt to the available screen width.
